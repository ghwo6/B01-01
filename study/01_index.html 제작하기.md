1. 간단한 index.html 기본 코드

텍스트 편집기(메모장, VS Code 등)를 열고 아래 코드를 복사해서 붙여넣습니다.
html
<!DOCTYPE html>
<html lang="ko">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>나의 첫 웹사이트</title>
</head>
<body>
    <h1>안녕하세요!</h1>
    <p>이것은 index.html 파일입니다.</p>
</body>
</html>


이 내용을 그대로 사용해도 좋을것 같다.
