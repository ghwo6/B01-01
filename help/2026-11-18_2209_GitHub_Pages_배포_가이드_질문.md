# GitHub Pages 배포 가이드

- **질문 일시:** 2026-11-18 22:09
- **질문 내용:** 현재 프로젝트(`ghwo6/B01-01`)를 GitHub Pages로 배포하는 방법 안내

---

## 1. 최신 코드를 GitHub에 Push하기

이미 `origin` (`git@github.com:ghwo6/B01-01.git`)의 `main` 브랜치가 연결되어 있으므로, 수정한 파일이 있다면 먼저 커밋하고 push합니다.

```bash
git add .
git commit -m "포트폴리오 웹사이트 구현 및 스타일 수정"
git push origin main
```

---

## 2. GitHub에서 Pages 설정 켜기

1. 브라우저에서 본인 저장소(`https://github.com/ghwo6/B01-01`)로 이동합니다.
2. 저장소 상단 메뉴에서 **Settings** 탭을 클릭합니다.
3. 왼쪽 사이드바의 **Code and automation** 아래에 있는 **Pages**를 클릭합니다.
4. **Build and deployment** 영역에서 아래와 같이 설정합니다.
   - **Source:** `Deploy from a branch`
   - **Branch:** `main` 선택 / 오른쪽 폴더는 `/ (root)` 선택
5. 오른쪽 **Save** 버튼을 클릭합니다.

---

## 3. 배포 주소 확인 및 동작 테스트

1. **Save**를 누른 뒤 **1~3분 정도** 기다렸다가 페이지를 새로고침합니다.
2. 상단에 **"Your site is live at `https://ghwo6.github.io/B01-01/`"** 안내가 뜨면 배포 완료입니다!
3. 해당 URL로 접속해 아래 항목들이 모두 잘 동작하는지 확인하세요.
   - [ ] 데스크톱 / 모바일 반응형 레이아웃
   - [ ] 햄버거 메뉴 열기/닫기 및 링크 클릭 시 자동 닫기
   - [ ] 다크 모드 토글 및 새로고침 후 유지 (`localStorage`)
   - [ ] 스크롤 탑 버튼(`↑`) 및 스크롤 애니메이션
   - [ ] GitHub API 프로젝트 카드 및 언어별 필터링
   - [ ] Contact 폼 검증 및 EmailJS 전송
4. 확인이 끝나면 **데스크톱 / 모바일 / 다크 모드** 스크린샷을 찍어두고, `README.md`에 배포 URL과 함께 정리하면 제출 준비가 끝납니다!
