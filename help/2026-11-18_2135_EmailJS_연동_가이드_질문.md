# EmailJS 연동 구현 가이드 (순수 `fetch` 방식)

- **질문 일시:** 2026-11-18 21:35
- **질문 내용:** Contact 폼에 EmailJS 연결하기 (`todolist/todolist.md` 보너스 과제)

> [!NOTE]
> `todolist/todolist.md`의 **"외부 라이브러리 사용 금지"** 규칙을 지키면서도 EmailJS를 쓸 수 있도록, 별도 SDK 스크립트를 추가하지 않고 **순수 `fetch` + `async/await`로 EmailJS REST API를 호출**하는 방식을 안내합니다.

---

## 1. EmailJS 사이트에서 사전 준비하기

1. [EmailJS 공식 사이트](https://www.emailjs.com/)에 회원가입 / 로그인합니다.
2. **Email Services** 메뉴 → **Add New Service** → Gmail 등 본인 이메일을 연결하고 **Service ID**를 복사해 둡니다. (예: `service_xxxxxxx`)
3. **Email Templates** 메뉴 → 기본 제공되는 **Contact Us** 템플릿을 그대로 사용해도 됩니다.
   - 현재 템플릿에 들어있는 변수:
     - Subject(제목): `{{title}}`
     - Content(본문): `{{name}}`, `{{time}}`, `{{message}}`
     - 오른쪽 **From Name**: `{{name}}` / **Reply To**: `{{email}}` (이미 잘 설정되어 있음!)
   - 템플릿 상단의 **Settings** 탭을 누르면 **Template ID**를 확인할 수 있습니다. (예: `template_xxxxxxx`)
   - 만약 내용을 수정했다면 오른쪽 위 파란색 **Save** 버튼을 꼭 눌러주세요.
4. 오른쪽 위 계정 이름 클릭 → **Account** → **API Keys**에서 **Public Key**를 복사해 둡니다. (예: `xxxxxxxxxxxxxxx`)

## 2. JavaScript 수정 (`js/script.js`)

기존 `form.addEventListener('submit', ...)` 부분을 `async` 함수로 바꾸고, 검증이 통과했을 때 EmailJS API로 데이터를 전송하도록 수정합니다.

```javascript
// 제출 검증 및 EmailJS 전송 (submit 이벤트)
form.addEventListener('submit', async (event) => { // fetch에 await를 쓰기 위해 async 추가
    event.preventDefault(); // 폼 제출 시 페이지가 새로고침되는 기본 동작 막기
    successMsg.textContent = ''; // 이전 성공/안내 메시지 초기화

    const nErr = getNameError(nameInput.value); // 이름 입력값 검사
    const eErr = getEmailError(emailInput.value); // 이메일 입력값 검사
    const mErr = getMessageError(messageInput.value); // 메시지 입력값 검사

    showFieldError(nameInput, nameError, nErr); // 이름 에러 화면 표시
    showFieldError(emailInput, emailError, eErr); // 이메일 에러 화면 표시
    showFieldError(messageInput, messageError, mErr); // 메시지 에러 화면 표시

    if (nErr || eErr || mErr) { // 셋 중 하나라도 에러가 있으면
        return; // 전송하지 않고 여기서 함수 종료
    }

    const submitBtn = form.querySelector('button[type="submit"]'); // 보내기 버튼 선택
    submitBtn.disabled = true; // 전송 중에 중복 클릭하지 못하도록 버튼 비활성화
    submitBtn.textContent = '전송 중...'; // 사용자에게 진행 중임을 표시

    // EmailJS API에 보낼 데이터 객체 만들기 (본인의 ID/Key로 교체하세요!)
    const payload = {
        service_id: 'YOUR_SERVICE_ID',   // 1단계에서 복사한 Service ID
        template_id: 'YOUR_TEMPLATE_ID', // 1단계에서 복사한 Template ID
        user_id: 'YOUR_PUBLIC_KEY',      // 1단계에서 복사한 Public Key
        template_params: {               // 템플릿의 {{title}}, {{name}}, {{time}}, {{email}}, {{message}}와 이름이 같아야 함
            title: '포트폴리오 사이트 문의',       // 템플릿 Subject의 {{title}}에 들어갈 제목
            name: nameInput.value.trim(),       // 앞뒤 공백 제거한 이름 ({{name}})
            email: emailInput.value.trim(),     // 앞뒤 공백 제거한 이메일 (Reply To의 {{email}})
            message: messageInput.value.trim(), // 앞뒤 공백 제거한 메시지 ({{message}})
            time: new Date().toLocaleString('ko-KR'), // 현재 시간을 한국 형식으로 넣음 ({{time}})
        },
    };

    try {
        const response = await fetch('https://api.emailjs.com/api/v1.0/email/send', { // EmailJS 전송 주소로 요청
            method: 'POST', // 데이터를 서버로 보내므로 POST 방식 사용
            headers: {
                'Content-Type': 'application/json', // 보내는 데이터가 JSON 형식임을 알려줌
            },
            body: JSON.stringify(payload), // JS 객체를 JSON 문자열로 변환해서 전송
        });

        if (!response.ok) { // 응답 상태 코드가 200번대가 아니면(실패 시)
            throw new Error(`전송 실패 (HTTP ${response.status})`); // catch 블록으로 에러 던짐
        }

        successMsg.textContent = '문의가 성공적으로 전송되었습니다!'; // 성공 메시지 표시
        form.reset(); // 입력한 폼 내용 비우기
    } catch (error) {
        alert('메일 전송에 실패했습니다. 잠시 후 다시 시도해 주세요.'); // 실패 시 사용자에게 알림
        console.error(error); // 개발자 도구 콘솔에 상세 에러 기록
    } finally {
        submitBtn.disabled = false; // 성공하든 실패하든 버튼 다시 활성화
        submitBtn.textContent = '보내기'; // 버튼 글자 원래대로 복구
    }
});
```
