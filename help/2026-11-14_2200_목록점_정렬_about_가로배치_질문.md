# `<li>` 점 정렬 & `#about` 이미지-글 가로 배치 방법

- 일시: 2026-11-14 22:00
- 질문:
  1. `<ul><li>`를 쓰면서 `<li>`의 점(`•`)이 글자와 떨어져 너무 왼쪽에 있는데 어떻게 해야 할까?
  2. `#about` 안에 Flexbox를 넣어서 `이미지 - 글(p 여러 개)` 형태로 가로 배치하려면 어떻게 해야 할까?
  3. 콘솔 오류는 `favicon`만 뜨는 상태인데 괜찮을까?

---

## 1. `<li>`의 점(`•`)이 너무 왼쪽에 있는 이유와 해결법

`section`에 `text-align: center;`를 주면 **글자(`파이썬`)**만 가운데로 이동하고, `<ul>`의 기본 점(`•`)은 바깥쪽(`list-style-position: outside`) 왼쪽 여백에 그대로 남아 있어서 글자와 멀어집니다.

원하는 모양에 따라 아래 3가지 중 하나를 선택해 `ul`에 적용하세요.

### 방법 A. 점(`•`) 없애고 가로 배지처럼 나열 (포트폴리오 추천)
```css
#skills ul {
    list-style: none;        /* 점 제거 */
    padding: 0;
    display: flex;
    justify-content: center;
    flex-wrap: wrap;
    gap: 0.75rem;
}
```

### 방법 B. 점(`•`)을 유지하되 글자 바로 옆에 붙이기
```css
#skills ul {
    list-style-position: inside; /* 점을 글자 안쪽으로 */
    padding: 0;
}
```

### 방법 C. 목록 전체를 묶어서 왼쪽 줄맞춤 유지한 채 가운데 놓기
항목이 여러 줄일 때 세로 줄이 깔끔하게 맞습니다.
```css
#skills ul {
    display: inline-block;
    text-align: left;
}
```

> 💡 **HTML 문법 참고:** `<ul><h3>기술 스택</h3></ul>`처럼 `<ul>` 안에 제목 태그를 넣지 말고, `<h3>기술 스택</h3>`은 `<ul>` 바깥 위에 단독으로 두는 것이 올바른 HTML 문법입니다.

## 2. `#about`에서 `이미지 - 글(p 여러 개)` 가로 배치하는 법

지금 구조 그대로 `#about`에 `display: flex`를 주면 **`<h1>`과 `<p>` 4개까지 전부 가로 1줄로 나란히** 서 버립니다.
**"이미지 1개"와 "글 묶음 1개"**가 나란히 놓이도록 먼저 `<div>`로 2단 구조를 만들어야 합니다.

### ① HTML 구조 묶기
```html
<section id="about">
    <h2>자기소개</h2>

    <div class="about-content">
        <img src="images/reg_made_in_abyss.webp" alt="만화 캐릭터" class="profile-img">

        <div class="about-text">
            <p>안녕하세요</p>
            <p>배우는걸 즐기는 김호재입니다.</p>
            <p>남들과 함께 공부하며 익히는</p>
            <p>코디세이 생활이 되었으면 합니다.</p>
        </div>
    </div>
</section>
```
- `.about-content`: 이미지와 글 덩어리를 **나란히 놓는 부모(Flex 컨테이너)**
- `.about-text`: 여러 개의 `<p>`를 **하나의 세로 글 덩어리**로 묶어 주는 래퍼

### ② CSS 작성 (모바일: 세로 → 768px 이상: 가로)
```css
.about-content {
    display: flex;
    flex-direction: column;   /* 모바일: 이미지 위, 글 아래 */
    align-items: center;
    gap: 2rem;
    margin-top: 1.5rem;
}

.about-text {
    text-align: center;       /* 모바일에서는 가운데 정렬 */
}

@media (min-width: 768px) {
    .about-content {
        flex-direction: row;  /* 태블릿 이상: 이미지 왼쪽, 글 오른쪽 */
        justify-content: center;
    }

    .about-text {
        text-align: left;     /* 가로 배치일 때는 왼쪽 정렬이 읽기 편함 */
    }
}
```

### ③ `.profile-img` 크기 팁
현재 `%`(`max-width: 20%`)로 되어 있는데, Flex 안에서는 고정 크기(`px`)를 주는 편이 화면 크기가 변해도 이미지가 너무 작아지거나 찌그러지지 않습니다.
```css
.profile-img {
    width: 180px;
    height: 180px;
    object-fit: cover;
    border-radius: 50%;       /* 동그란 프로필을 원할 때 */
    flex-shrink: 0;           /* 글이 길어져도 이미지가 찌그러지지 않게 */
}
```

## 3. `favicon` 콘솔 오류에 대해

`favicon.ico` 404 오류는 브라우저가 탭에 표시할 아이콘 파일을 찾다가 없어서 띄우는 것일 뿐, **JS 코드 오류는 모두 해결되어 정상 동작 중이라는 의미**입니다.

콘솔창에서 이 메시지마저 안 보고 싶다면 `index.html`의 `<head>` 안에 아래 한 줄을 추가하면 사라집니다.
```html
<link rel="icon" href="data:,">
```
