## 답변 1. 필요한 시맨틱 태그 정리

`todolist/todolist.md`의 **2. HTML 구조** 항목(43~55행)을 기준으로 정리했습니다.

### 필수 시맨틱 태그 (43행)

| 태그 | 용도 | 들어갈 섹션 |
|---|---|---|
| `<header>` | 페이지 상단 영역 | 로고, 메뉴, 다크 모드 버튼, 햄버거 버튼 |
| `<nav>` | 네비게이션 메뉴 | `href="#about"` 같은 앵커 링크 |
| `<main>` | 본문 (페이지에 하나만 사용) | Hero ~ Contact 섹션을 감싸는 영역 |
| `<section>` | 주제별로 나눈 구역 | Hero, About, Skills, Projects, Contact |
| `<article>` | 혼자 떼어내도 의미가 있는 콘텐츠 | Projects의 GitHub 저장소 카드 하나하나 |
| `<footer>` | 페이지 하단 | 저작권, 소셜 링크 |

### 사이드바(`<aside>`) 관련
**todolist에는 사이드바(`<aside>`)가 필수 항목으로 없습니다.** 요구 레이아웃은 "상단 네비게이션(Flexbox) + 세로로 이어지는 섹션" 구조입니다. 사이드바를 꼭 넣고 싶다면 `<aside>`를 쓰면 되지만, 선택 사항이고 모바일 반응형 작업이 더 늘어납니다.

### 함께 쓰면 좋은 태그
- `<form>`, `<label for>`, `<input>`, `<textarea>`: Contact 폼 (54행, `for`와 `id`를 맞춰야 함)
- `<button>`: 다크 모드, 햄버거, 스크롤 탑(55행), 다시 시도 버튼
- `<img alt="...">`: 프로필 사진 (53행, 의미 있는 `alt` 필수)
- `<ul>`/`<li>`: 메뉴 목록, 기술 스택 목록

### 뼈대 예시
```html
<body>
  <header>
    <a href="#hero" class="logo">로고</a>
    <nav>
      <ul>
        <li><a href="#about">About</a></li>
        <li><a href="#skills">Skills</a></li>
        <li><a href="#projects">Projects</a></li>
        <li><a href="#contact">Contact</a></li>
      </ul>
    </nav>
    <button class="theme-toggle">다크 모드</button>
    <button class="hamburger">메뉴</button>
  </header>

  <main>
    <section id="hero">인사말 + CTA 버튼</section>
    <section id="about">자기소개 + <img alt="프로필 사진"></section>
    <section id="skills"><ul>기술 스택</ul></section>
    <section id="projects">
      <div class="status">로딩/에러/빈 상태</div>
      <!-- JS로 <article> 카드 생성 -->
    </section>
    <section id="contact"><form>이름/이메일/메시지</form></section>
  </main>

  <footer>© 2026 · GitHub · LinkedIn</footer>
  <button class="scroll-top">↑</button>
</body>
```

cta : call to Ation - 행동 유도
