# HTML 내용을 세로(vertical) / 가로(horizontal)로 나열하는 법

- 일시: 2026-11-12 19:36
- 질문: html 안의 내용을 버티컬하게 나열하는 방법, 호리젠탈하게 나열하는 방법 알려줘

---

## 0. 핵심 한 줄

> **HTML은 "무엇을" 넣을지, 배치(세로/가로)는 CSS가 정합니다.**
> HTML에 `style="..."`을 쓰면 **인라인 스타일 금지 규칙**(todolist 15행)에 걸리니, **class를 붙이고 CSS에서 배치**하세요.

---

## 1. 기본 동작부터 이해하기: block vs inline

아무 CSS도 없을 때 태그들은 원래 성질대로 놓입니다.

| 종류 | 대표 태그 | 기본 배치 |
|---|---|---|
| **block** | `div`, `section`, `p`, `h1~h6`, `ul`, `li`, `header`, `nav`, `form` | 한 줄을 통째로 차지 → **세로로 쌓임** |
| **inline** | `a`, `span`, `img`, `button`, `strong`, `label` | 글자처럼 옆으로 흐름 → **가로로 붙음** |

지금 `index.html`에서 보면:
- Hero의 `<h2>`, `<h1>`, `<p>`, `<p>` → block이라 **이미 세로로** 쌓임
- Hero의 `<a class="btn">` 두 개 → inline이라 **이미 가로로** 붙어 있음
- 헤더의 `<li>` 메뉴들 → block이라 **세로로** 쌓여 있음 (가로로 바꾸고 싶은 부분)

즉, **기본 성질을 바꾸고 싶을 때** CSS를 씁니다. 가장 쉽고 추천하는 방법이 **Flexbox**입니다.

---

## 2. Flexbox로 가로 / 세로 정하기 (추천)

### 규칙
1. **나열하고 싶은 요소들을 하나의 부모로 감싼다**
2. **부모에** `display: flex;`를 준다
3. 방향은 `flex-direction`으로 정한다

| `flex-direction` | 결과 |
|---|---|
| `row` (기본값) | **가로** 나열 → |
| `column` | **세로** 나열 ↓ |

> ⚠️ 가장 많이 하는 실수: `display: flex`를 **자식**에 주는 것. 반드시 **감싸는 부모**에 줘야 합니다.

### 2-1. 가로로 나열하기

```html
<div class="row">
    <div>A</div>
    <div>B</div>
    <div>C</div>
</div>
```
```css
.row {
    display: flex;          /* flex-direction: row 가 기본값이라 생략 가능 */
    gap: 1rem;              /* 요소 사이 간격 */
}
```
결과: `A  B  C`

### 2-2. 세로로 나열하기

```html
<div class="column">
    <a href="#">A</a>
    <a href="#">B</a>
    <a href="#">C</a>
</div>
```
```css
.column {
    display: flex;
    flex-direction: column;
    gap: 1rem;
}
```
결과:
```
A
B
C
```
> `<a>`처럼 원래 가로로 붙는 inline 요소도 이렇게 하면 세로로 바뀝니다.

## 3. 정렬 옵션 (자주 쓰는 3가지)

| 속성 | 하는 일 | 자주 쓰는 값 |
|---|---|---|
| `gap` | 요소 사이 간격 | `1rem`, `20px` |
| `justify-content` | **나열 방향**으로 정렬 | `flex-start`, `center`, `space-between`, `flex-end` |
| `align-items` | **나열 방향과 수직**으로 정렬 | `stretch`(기본), `center`, `flex-start` |

> 💡 헷갈리면: `row`일 땐 justify = 가로, align = 세로. `column`일 땐 **반대**로 바뀝니다.

```
justify-content: space-between  (row)
┌──────────────────────────────┐
│ [A]          [B]          [C] │
└──────────────────────────────┘

justify-content: center  (row)
┌──────────────────────────────┐
│         [A] [B] [C]           │
└──────────────────────────────┘
```

화면이 좁을 때 줄바꿈시키려면: `flex-wrap: wrap;`

## 4. 내 `index.html`에 적용해 보기 (직접 해 보세요)

### 4-1. 헤더: 로고 왼쪽, 메뉴 오른쪽 (todolist 65행)

```css
header {
    display: flex;
    justify-content: space-between;  /* 양 끝으로 벌리기 */
    align-items: center;             /* 세로 가운데 */
}

nav ul {
    display: flex;          /* li 메뉴들을 가로로 */
    gap: 1.5rem;
    list-style: none;       /* 앞의 점(•) 없애기 */
    margin: 0;
    padding: 0;
}
```
- `header`의 자식(로고, nav, 버튼들)이 가로로 놓임
- `nav ul`의 자식(`li` 4개)도 가로로 놓임
- → **flex는 중첩해서** 쓸 수 있습니다. 바깥도 flex, 안쪽도 flex.

### 4-2. Hero: 글은 세로, 버튼은 가로

Hero 글은 이미 세로라 그대로 둬도 되지만, **버튼 두 개만 묶어서** 가로 간격을 주면 깔끔합니다.

```html
<div class="hero-cta">
    <a href="#projects" class="btn">프로젝트</a>
    <a href="#contact" class="btn">연락하기</a>
</div>
```
```css
.hero-cta {
    display: flex;
    gap: 1rem;
}
```

### 4-3. About: 사진과 글을 가로로 (모바일에서는 세로)

지금 About은 `자기소개`라는 글자 + `img` + `<p>`가 섞여 있어요. 먼저 **글 부분을 하나로 묶습니다**.

```html
<section id="about" class="about">
    <img src="images/reg_made_in_abyss.webp" alt="..." class="profile-img">
    <div class="about-text">
        <h2>자기소개</h2>
        <p>안녕하세요</p>
    </div>
</section>
```
```css
/* 모바일 먼저: 세로 */
.about {
    display: flex;
    flex-direction: column;
    align-items: center;
    gap: 2rem;
}

/* 태블릿 이상: 가로 */
@media (min-width: 768px) {
    .about {
        flex-direction: row;
    }
}
```
→ 이것이 **모바일 퍼스트**(todolist 68~69행): 좁은 화면은 세로, 넓은 화면은 가로.

### 4-4. Skills: 지금 `<ul>` 사용법부터 수정

현재 코드:
```html
<ul>기술 스택</ul>
<ul>파이썬</ul>
```
`<ul>` 안에는 **`<li>`만** 들어가야 합니다. 이렇게 고치고:
```html
<h2>기술 스택</h2>
<ul class="skill-list">
    <li>Python</li>
    <li>HTML</li>
    <li>CSS</li>
</ul>
```
가로로 태그처럼 나열:
```css
.skill-list {
    display: flex;
    flex-wrap: wrap;   /* 많아지면 다음 줄로 */
    gap: 0.5rem;
    list-style: none;
    padding: 0;
}
```

## 5. 다른 방법들 (참고)

| 방법 | 언제 쓰나 |
|---|---|
| **Flexbox** | 한 방향(가로 **또는** 세로) 나열. 메뉴, 버튼 묶음, 사진+글 → **대부분 이걸로 충분** |
| **Grid** | 가로 **와** 세로를 동시에 맞추는 격자. Projects 카드 목록 (todolist 66행) |
| `display: inline-block` | 옛날 방식. 간격 조절이 불편해서 비추천 |
| `float` | 아주 옛날 방식. 레이아웃용으로는 쓰지 않기 |

Grid 맛보기 (Projects 카드용):
```css
.project-list {
    display: grid;
    grid-template-columns: repeat(auto-fit, minmax(250px, 1fr));
    gap: 1.5rem;
}
```
→ 화면 너비에 따라 한 줄에 1개, 2개, 3개… 알아서 바뀝니다.

## 6. 확인하는 법

- Chrome에서 F12 → Elements 탭 → `display: flex`가 적용된 요소 옆에 **`flex` 배지**가 생김 → 클릭하면 배치 영역이 화면에 표시됨
- Styles 패널에서 `display: flex` 옆의 아이콘을 누르면 `flex-direction`, `justify-content`를 **클릭으로 바꿔 보며** 결과를 미리 볼 수 있음

## 7. 체크리스트

- [ ] 나열할 요소들을 **부모 하나로 감쌌는가**
- [ ] `display: flex`를 **부모에** 줬는가
- [ ] 가로면 `row`(기본), 세로면 `flex-direction: column`
- [ ] 간격은 `margin` 대신 `gap`으로
- [ ] 모바일은 세로, 큰 화면은 가로가 필요하면 `@media (min-width: 768px)` 안에서 방향 바꾸기
- [ ] HTML에 `style="..."` 안 썼는가
