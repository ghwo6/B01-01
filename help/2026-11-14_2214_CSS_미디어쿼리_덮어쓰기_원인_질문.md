# CSS `@media` 쿼리가 위에서는 안 되고 아래에 쓰니 되는 이유 (Cascade 규칙)

- 일시: 2026-11-14 22:14
- 질문: `@media (min-width: 768px)` 안에 `.about-content`와 `.about-text`를 넣었을 때 위쪽 미디어 쿼리에서는 적용이 안 되고, 아래쪽에 새로 `@media (min-width: 768px)`를 만들어 넣으니 적용된다. 아래에 있는 코드가 덮어씌워서 그런가?

---

## 1. 결론부터

**네, 정확히 맞습니다! CSS는 같은 우선순위라면 "더 아래(나중)에 적힌 코드"가 위 코드를 덮어씁니다.**

---

## 2. 왜 그런 일이 생겼을까? (`css/style.css` 순서 확인)

현재 `css/style.css`의 순서를 위에서 아래로 보면 이렇습니다.

```css
/* ① 93~116행: 위쪽 미디어 쿼리 */
@media (min-width: 768px) {
    .about-content { flex-direction: row; }    /* 먼저 적용됨 */
    .about-text    { text-align: left; }
}

/* ② 122~133행: 기본(모바일) 스타일 */
.about-content { flex-direction: column; }     /* ← 여기가 더 아래라 ①을 덮어씀! */
.about-text    { text-align: center; }

/* ③ 135~144행: 아래쪽 미디어 쿼리 */
@media (min-width: 768px) {
    .about-content { flex-direction: row; }    /* ← ②보다 더 아래라 최종 승리! */
    .about-text    { text-align: left; }
}
```

### 꼭 알아야 할 CSS 핵심 원리 2가지
1. **`@media (...)`는 우선순위(점수)를 올려주지 않습니다.**
   - `@media` 안에 들어있는 `.about-content`나 밖에 있는 `.about-content`나 **둘 다 클래스 1개(우선순위 점수 동일)**입니다.
   - `@media`는 단지 **"화면이 768px 이상일 때만 이 블록을 켜라"**라는 조건문일 뿐입니다.
2. **우선순위가 같으면 무조건 "나중에(아래에) 나온 줄"이 이깁니다. (Cascade, 폭포수 규칙)**
   - 그래서 ①만 있었을 때는, 768px 이상 화면에서도 ①(`row`)이 켜진 직후 ②(`column`)가 **더 아래에 있어서 덮어써 버렸기 때문에** 가로 배치가 안 된 것입니다.
   - ③을 ②보다 아래에 적으니 ③(`row`)이 ②(`column`)를 다시 덮어써서 정상 동작한 것입니다.

---

## 3. 실무에서 추천하는 깔끔한 정리 방법

앞으로 이런 덮어쓰기 실수를 막으려면 **모바일 퍼스트 CSS 순서**를 지키면 됩니다.

> **규칙: 기본(모바일) 스타일은 전부 위쪽에, `@media (min-width: ...)`는 전부 아래쪽에 둔다.**

### 방법 A. 파일 맨 아래에 `@media (min-width: 768px)` 블록을 딱 1개만 두기 (가장 추천)
```css
/* 1. 모든 기본(모바일) 스타일을 위에 작성 */
.nav { ... }
.about-content { flex-direction: column; ... }
.about-text { text-align: center; }

/* 2. 파일 맨 아래에 태블릿 이상 미디어 쿼리를 하나로 모으기 */
@media (min-width: 768px) {
    .hamburger { display: none; }
    .nav { position: static; width: auto; max-height: none; overflow: visible; }
    .nav-list { flex-direction: row; padding: 0; }

    .about-content { flex-direction: row; justify-content: center; }
    .about-text { text-align: left; }
}
```
- 이렇게 하면 미디어 쿼리가 두 군데로 흩어지지 않고, **기본 스타일이 미디어 쿼리를 덮어쓰는 버그가 원천 차단**됩니다.

### 방법 B. 섹션별로 묶고 싶다면
각 섹션의 기본 스타일을 먼저 쓰고, 그 **바로 아래**에 해당 섹션의 `@media`를 두어야 합니다. (즉, 지금 코드에서 ①에 있던 `.about-content`, `.about-text` 중복 부분만 지우고 ② → ③ 순서로 두는 방식)
