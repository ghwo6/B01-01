# 구글 폰트 주소 분석

- 일시: 2026-11-14 19:31
- 질문: `study/example/02/02_01_01_googlefont사용.md`의 두 `<link>` 태그가 각각 무엇을 의미하는지, 아래 링크가 `Noto Sans KR`, `Jua`, `Roboto`를 동시에 가져오는 주소인지, 그리고 `index.html`과 CSS(`*` 선택자 등)에 적용할 때 주의할 점이 무엇인지?

---

## 1. 결론부터

**네, 아래쪽 링크 하나가 `Jua`, `Noto Sans KR`, `Roboto` 세 가지 폰트를 동시에 가져오는 주소입니다.**

따라서 `index.html`의 `<head>`에는 두 개를 다 넣을 필요 없이 **두 번째 링크 하나만** 넣으면 됩니다. (둘 다 넣으면 `Noto Sans KR`을 중복 요청하게 됩니다.)

---

## 2. 두 링크 비교 분석

### 첫 번째 링크
```html
<link href="https://fonts.googleapis.com/css2?family=Noto+Sans+KR:wght@100..900&display=swap" rel="stylesheet">
```
- `Noto Sans KR` 폰트 **1개만** 굵기 `100..900` 범위로 가져옵니다.

### 두 번째 링크
```html
<link href="https://fonts.googleapis.com/css2?family=Jua&family=Noto+Sans+KR:wght@100..900&family=Roboto:ital,wght@0,100..900;1,100..900&display=swap" rel="stylesheet">
```
URL 파라미터를 `&` 기준으로 쪼개 보면 다음과 같습니다. (`family=`가 나올 때마다 폰트 1개씩 추가되며, 폰트 이름의 공백은 `+`로 표기합니다.)

| 파라미터 | 의미 |
|---|---|
| `family=Jua` | `Jua` 폰트 요청 (단일 굵기 400만 제공되는 폰트라 별도 `wght` 없음) |
| `family=Noto+Sans+KR:wght@100..900` | `Noto Sans KR` 폰트 요청, 굵기(`wght`) 100(가장 얇음) ~ 900(가장 굵음) 전체 범위 |
| `family=Roboto:ital,wght@0,100..900;1,100..900` | `Roboto` 폰트 요청 (`ital`: 0=일반체, 1=이탤릭체)<br>- `0,100..900` : 일반체 굵기 100~900<br>- `1,100..900` : 이탤릭체 굵기 100~900 |
| `display=swap` | 폰트 다운로드 중에도 글자가 안 보이는 현상을 막기 위해 기본 폰트를 먼저 보여 주고, 다운로드 완료 시 웹 폰트로 교체 |

---

## 3. `index.html`에 넣을 때 주의할 점

`study/example/02/02_01_01_googlefont사용.md` 예제 상단의 `preconnect` 두 줄에는 `goolgeapis` 오타와 `http://`가 섞여 있습니다. 실제 `index.html`에는 아래처럼 정확히 적어 주세요.

```html
<link rel="preconnect" href="https://fonts.googleapis.com">
<link rel="preconnect" href="https://fonts.gstatic.com" crossorigin>
<link href="https://fonts.googleapis.com/css2?family=Jua&family=Noto+Sans+KR:wght@100..900&family=Roboto:ital,wght@0,100..900;1,100..900&display=swap" rel="stylesheet">
```

## 4. CSS에서 적용할 때 주의할 점 (`*` vs `body`)

### `*` (전체 선택자)에 `font-family`를 줄 때의 단점
```css
* {
    font-family: "Noto Sans KR", sans-serif;
}
```
- 모든 태그에 바로 적용되긴 하지만, 나중에 **Font Awesome 같은 아이콘 폰트**를 쓰거나 `<code>` 같은 고정폭 글꼴을 쓸 때도 전부 덮어써서 아이콘이 깨질 수 있습니다.

### 권장 방식: `body`와 폼 요소에 지정하기
`<button>`, `<input>`, `<textarea>`는 브라우저 기본 스타일 때문에 `body`의 폰트를 자동으로 물려받지 않는 경우가 있으므로 함께 묶어 주는 것이 좋습니다.

```css
body, button, input, textarea {
    font-family: "Roboto", "Noto Sans KR", sans-serif;
}

h1 {
    font-family: "Jua", sans-serif;
}
```

- **폰트 나열 순서 팁:** `"Roboto", "Noto Sans KR", sans-serif`처럼 영문 폰트를 앞에 두고 한글 폰트를 뒤에 두면, **영문과 숫자는 `Roboto`**, `Roboto`에 없는 **한글은 자동으로 뒤의 `Noto Sans KR`**이 적용되어 깔끔하게 섞여 보입니다.
- `Jua`처럼 개성이 강한 폰트는 본문 전체보다는 제목(`h1`)이나 강조 영역에만 부분적으로 사용하는 것을 추천합니다.
