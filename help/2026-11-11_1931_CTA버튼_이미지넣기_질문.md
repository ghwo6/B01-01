- 일시: 2026-11-11 19:31

---

## 1. CTA 버튼이란?

**CTA = Call To Action (행동 유도).** 방문자에게 "다음에 이걸 해 주세요"라고 안내하는 눈에 띄는 버튼입니다.

포트폴리오 Hero 섹션에서는 보통 이렇게 씁니다.
- **View Projects** → 누르면 Projects 섹션으로 이동
- **Contact** → 누르면 Contact 폼으로 이동

페이지 안에서 이동하는 것이므로 `<button>`이 아니라 **앵커 링크 `<a href="#id">`** 로 만듭니다. 버튼처럼 보이게 하는 건 CSS 클래스가 맡습니다.

```html
<section id="hero">
    <h1>안녕하세요! 저는 홍길동입니다.</h1>
    <p>프론트엔드 개발자를 꿈꾸고 있습니다.</p>

    <a href="#projects" class="btn">View Projects</a>
    <a href="#contact" class="btn btn-outline">Contact</a>
</section>
```

> **`<a>`와 `<button>` 구분하기**
> - 어딘가로 **이동**한다 → `<a href="...">` (CTA, 네비 메뉴)
> - 페이지에서 **동작**을 실행한다 → `<button type="button">` (다크 모드, 햄버거, 스크롤 탑)

## 2. 이미지 넣는 법

### 1단계: 이미지 파일 준비
프로젝트에 `images` 폴더를 만들고 사진을 넣습니다.
```
B01-01/
├── index.html
└── images/
    └── profile.jpg
```
> 파일 이름은 **영어 소문자, 공백 없이** 짓는 게 안전합니다. (`내 사진.JPG` ❌ → `profile.jpg` ✅) GitHub Pages는 대소문자를 구분해서, `Profile.jpg`를 `profile.jpg`로 불러오면 배포 후 이미지가 깨집니다.

### 2단계: `<img>` 태그 작성
```html
<section id="about">
    <h2>About</h2>
    <img src="images/profile.jpg" alt="웃고 있는 홍길동의 프로필 사진">
    <p>자기소개 내용</p>
</section>
```

| 속성 | 의미 |
|---|---|
| `src` | 이미지 **경로**. `index.html` 위치를 기준으로 적음 |
| `alt` | 이미지가 안 보일 때나 스크린리더가 읽어 줄 **설명** (todolist 53행: 의미 있는 `alt` 필수) |

- `<img>`는 닫는 태그가 없습니다.
- `alt`는 "이미지", "사진"처럼 쓰지 말고 **무엇이 찍혀 있는지** 적습니다.

### 경로 적는 법
| 상황 | `src` 예시 |
|---|---|
| `index.html`과 같은 폴더 | `profile.jpg` |
| `images` 폴더 안 | `images/profile.jpg` |
| CSS 파일(`css/style.css`)에서 이미지를 부를 때 | `../images/profile.jpg` (한 폴더 위로 올라감) |

### 크기·모양 조절은 CSS에서
`<img style="width:200px">`처럼 쓰면 **인라인 스타일 금지 규칙**에 걸립니다. 클래스를 붙여서 CSS에서 조절하세요.
```html
<img src="images/profile.jpg" alt="웃고 있는 홍길동의 프로필 사진" class="profile-img">
```
```css
.profile-img {
    width: 180px;
    height: 180px;
    border-radius: 50%;  /* 동그랗게 */
    object-fit: cover;   /* 비율 유지하며 꽉 채우기 */
}
```

### 이미지가 안 보일 때 확인할 것
1. 파일 이름과 확장자가 정확한지 (`.jpg` / `.jpeg` / `.png`)
2. 대소문자가 같은지
3. `src` 경로가 `index.html` 기준으로 맞는지
4. 브라우저 개발자 도구(F12) → Console에 404 에러가 있는지
