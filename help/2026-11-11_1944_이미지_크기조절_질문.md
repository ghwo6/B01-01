# 이미지 크기를 화면에 맞춰 조절하는 법

- 일시: 2026-11-11 19:44
- 질문: 이미지가 너무 커. 동적으로 사이즈를 조절해야 할 것 같은데 어떻게 하니?
- 현재 상태: `index.html` 35행 `<img src="images/reg_made_in_abyss.webp" alt="프로필 사진">`, CSS 파일은 아직 없음

---

## 왜 크게 나오나?
`<img>`는 CSS가 없으면 **원본 해상도 그대로** 나옵니다. 원본이 1500px이면 화면보다 넓어져서 가로 스크롤까지 생깁니다.

> `<img width="200">`이나 `style="width:200px"`로 고정하는 건 피하세요. `style`은 인라인 스타일 금지 규칙에 걸리고, 고정 크기는 화면 크기에 맞춰 바뀌지 않습니다.

---

## 1단계: CSS 파일 만들고 연결
CSS 파일이 아직 없으니 먼저 만듭니다.
```
B01-01/
├── index.html
├── css/
│   └── style.css   ← 새로 만들기
└── images/
    └── reg_made_in_abyss.webp
```
`index.html`의 `<head>` 안, `<title>` 아래에 추가합니다.
```html
<link rel="stylesheet" href="css/style.css">
```

## 2단계: 이미지에 클래스 붙이기
```html
<section id="about">
    <h2>About</h2>
    <img src="images/reg_made_in_abyss.webp" alt="레그 캐릭터 이미지" class="profile-img">
    <p>자기소개 내용</p>
</section>
```
> `alt`는 "프로필 사진"보다 **실제로 무엇이 보이는지** 쓰는 게 좋습니다. (todolist 53행)

## 3단계: CSS로 크기 조절

### 방법 A. 기본 안전장치 (모든 이미지에 추천)
```css
img {
    max-width: 100%;  /* 부모(섹션)보다 절대 넓어지지 않음 */
    height: auto;     /* 가로에 맞춰 세로 비율 유지 */
    display: block;
}
```
화면이 좁아지면 이미지도 같이 줄어듭니다. 하지만 **넓은 화면에서는 여전히 원본 크기**까지 커질 수 있습니다.

### 방법 B. 최대 크기를 정하고, 작은 화면에선 줄어들게
```css
.profile-img {
    width: 100%;
    max-width: 250px;  /* 아무리 커도 250px까지만 */
    height: auto;
    margin: 0 auto;    /* 가운데 정렬 (display: block 필요) */
}
```
- 넓은 화면에서는 250px로 고정됩니다.
- 250px보다 좁은 화면에서는 화면 폭에 맞춰 줄어듭니다.

### 방법 C. 화면 크기에 비례해서 부드럽게 (`clamp`)
```css
.profile-img {
    width: clamp(150px, 30vw, 300px);
    height: auto;
}
```
`clamp(최소, 기본, 최대)`
- `30vw` = 화면 너비의 30%
- 아무리 작아도 150px, 아무리 커도 300px

### 방법 D. 미디어 쿼리로 단계별 크기 (모바일 퍼스트)
```css
.profile-img {
    width: 160px;   /* 모바일 */
}

@media (min-width: 768px) {
    .profile-img { width: 220px; }   /* 태블릿 */
}

@media (min-width: 1024px) {
    .profile-img { width: 280px; }   /* 데스크톱 */
}
```
todolist 3번의 브레이크포인트(`768px`, `1024px`) 연습에도 좋습니다.

---

## 4단계(선택): 동그란 프로필 사진
원본이 정사각형이 아니면 그냥 `border-radius: 50%`만 주면 타원이 됩니다. **가로세로를 같게 하고 `object-fit: cover`** 를 씁니다.
```css
.profile-img {
    width: clamp(150px, 30vw, 250px);
    aspect-ratio: 1 / 1;   /* 정사각형 */
    object-fit: cover;     /* 비율 유지하면서 꽉 채우고 넘치는 부분은 잘라냄 */
    border-radius: 50%;    /* 동그랗게 */
}
```

| `object-fit` 값 | 결과 |
|---|---|
| `fill` (기본) | 틀에 맞춰 늘림 → 찌그러질 수 있음 |
| `cover` | 비율 유지, 꽉 채움, 넘치는 부분 잘림 ✅ 프로필에 적합 |
| `contain` | 비율 유지, 전체가 보임, 빈 공간 생길 수 있음 |

---

## 추천 조합
**방법 A(전체 이미지 안전장치) + 방법 C 또는 B(프로필 크기 제한)** 를 같이 쓰면 됩니다.
```css
img {
    max-width: 100%;
    height: auto;
    display: block;
}

.profile-img {
    width: clamp(150px, 30vw, 250px);
    aspect-ratio: 1 / 1;
    object-fit: cover;
    border-radius: 50%;
    margin: 0 auto;
}
```

## 확인 방법
- 브라우저 창 너비를 줄였다 늘렸다 하면서 이미지 크기가 따라 바뀌는지 봅니다.
- 개발자 도구(F12) → 왼쪽 위 기기 아이콘(Toggle device toolbar)으로 모바일 화면에서도 확인합니다.
- 변화가 없으면: `<link>` 경로(`css/style.css`)와 `class="profile-img"` 철자를 확인하세요.

> 참고로 "동적"이라고 해서 JS가 필요한 건 아닙니다. 화면 크기에 따른 크기 조절은 **CSS만으로** 처리하는 게 정석입니다.
