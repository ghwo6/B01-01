## 1. 배포 전 점검
배포 후에 고치면 다시 push하고 기다려야 하니까, 로컬(Live Server)에서 먼저 확인합니다.

- [ ] **`index.html`이 저장소 최상위 폴더에 있음** (GitHub Pages는 `index.html`을 첫 화면으로 엽니다)
- [ ] 경로가 **상대 경로**임: `css/style.css` ✅, `/css/style.css` ❌, `C:\Users\...` ❌
- [ ] 파일 이름과 `src`/`href`의 **대소문자가 정확히 같음** (GitHub Pages는 대소문자를 구분하고, 맥/윈도우는 구분하지 않아서 로컬에선 멀쩡해 보임)
- [ ] 개발자 도구(F12) Console에 빨간 에러가 없음
- [ ] todolist 0번 규칙 점검: `var` 없음, `onclick` 없음, `style="..."` 없음, 외부 라이브러리 없음
- [ ] `.DS_Store` 같은 불필요한 파일이 올라가지 않음 (`.gitignore`에 추가)

> 규칙 위반은 VS Code 전체 검색(`Cmd + Shift + F`)으로 `var `, `onclick`, `style="`를 검색하면 빨리 찾을 수 있습니다.

## 2. GitHub에 push
이 프로젝트는 이미 GitHub 저장소(`origin/main`)와 연결되어 있습니다.
```bash
git status                 # 바뀐 파일 확인
git add .
git commit -m "feat: 포트폴리오 페이지 완성"
git push origin main
```
> 커밋은 마지막에 한 번에 하지 말고, 기능 하나 끝날 때마다 나눠서 하면 좋습니다. (예: `feat: 다크 모드 추가`, `feat: GitHub API 연동`)

## 3. GitHub Pages 설정
1. GitHub 저장소 페이지 → **Settings**
2. 왼쪽 메뉴 **Pages**
3. **Build and deployment** → Source: **Deploy from a branch**
4. Branch: **`main`**, 폴더: **`/ (root)`** → **Save**
5. 1~2분 기다린 뒤 새로고침하면 위쪽에 주소가 나옵니다.
   `Your site is live at https://아이디.github.io/저장소이름/`

> 진행 상황은 저장소의 **Actions** 탭에서 볼 수 있습니다. 초록 체크가 뜨면 배포 완료입니다.
> 저장소가 **Public**이어야 무료로 Pages를 쓸 수 있습니다.

### 이 저장소 구조에서 주의할 점
현재 저장소에는 `example/`, `study/`, `todolist/`, `help/` 폴더도 같이 있습니다. 배포해도 문제는 없지만 **이 폴더들도 주소로 접근할 수 있게 공개됩니다.** (예: `.../help/파일.md`) 공개하고 싶지 않은 내용이 있다면 따로 정리하세요.

## 4. 배포 URL에서 기능 확인 (todolist 155~159행)
| 항목 | 확인 방법 |
|---|---|
| 반응형 레이아웃 | 창 크기 조절 + F12 기기 모드 (iPhone, iPad), 휴대폰으로 직접 접속 |
| 햄버거 메뉴 | 모바일 폭에서 열기 / 닫기 / 링크 클릭 시 닫힘 |
| 다크 모드 | 전환 후 **새로고침해도 유지**되는지 |
| 스크롤 | 부드러운 이동, 60px 네비 변경, 300px 스크롤 탑 버튼, fade-in 애니메이션 |
| GitHub API | 카드가 뜨는지, Network → Offline으로 에러 + 다시 시도 확인 |
| 폼 검증 | 빈 제출, 잘못된 이메일, 성공 메시지 |
| 이미지 | 프로필 이미지가 깨지지 않는지 (대소문자 문제 확인) |

### 배포 후에만 생기는 문제
| 증상 | 원인 |
|---|---|
| 404 페이지 | `index.html`이 최상위에 없음, 또는 아직 배포 중 |
| CSS / JS가 안 먹힘 | 절대 경로(`/css/...`) 사용 → `css/...`로 수정 |
| 이미지만 깨짐 | 파일 이름 대소문자 불일치 |
| 수정했는데 그대로 | 브라우저 캐시 → `Cmd + Shift + R` 강력 새로고침, 또는 1~2분 대기 |

## 5. 스크린샷 3장 (todolist 173행)
| 종류 | 찍는 방법 |
|---|---|
| 데스크톱 | 브라우저 창을 넓게 → `Cmd + Shift + 4` 후 `Space` → 창 클릭 |
| 모바일 | F12 → 기기 아이콘 → iPhone 선택 → 개발자 도구 `⋮` 메뉴 → **Capture screenshot** |
| 다크 모드 | 다크 모드로 바꾼 뒤 데스크톱처럼 촬영 |

> 페이지 전체를 한 장으로 찍고 싶으면: F12 → `Cmd + Shift + P` → `full size screenshot` 입력 → **Capture full size screenshot**

```

└── screenshots/
    ├── desktop.png
    ├── mobile.png
    └── dark-mode.png
```
