# Hero 섹션은 어떻게 꾸미는 게 좋을까?

- 일시: 2026-11-12 19:25
- 질문: `index.html`을 수정하려는데 hero 섹션을 어떻게 꾸미는 게 나을까?

---

## 0. 먼저, 지금 코드에서 고칠 점 4가지

현재 코드 (`index.html` 27~41행):

```html
<section id="hero">
    <h2>안녕하세요!! 김호재라고 합니다.</h2>
    <p>코디세이 올인원 2기입니다.</p>
    <p>여러분들과 같이 공부하고 세상을 밝히고 싶습니다.</p>
    <p>호기심이 많습니다.</p>
    <p>원리에 대해 파악하는것을 좋아합니다.</p>

    <button>
        <a href="#projects" class="btn">프로젝트</a>
    </button>
    <button>
        <a href="#about" class="btn">연락하기</a>
    </button>
</section>
```

| # | 문제 | 왜 문제인가 | 어떻게 고치나 |
|---|---|---|---|
| 1 | `<button>` 안에 `<a>`가 들어 있음 | HTML 규칙상 **클릭할 수 있는 요소 안에 또 클릭할 수 있는 요소를 넣으면 안 됨**. 브라우저마다 동작이 다르고, 키보드 Tab 포커스가 두 번 걸림 | `<button>`을 지우고 `<a class="btn">`만 남기기 (→ `2026-11-11_1931_CTA버튼_이미지넣기_질문.md` 참고) |
| 2 | "연락하기"가 `#about`으로 이동함 | 버튼 이름과 이동하는 곳이 다름 | `href="#contact"`로 바꾸기 |
| 3 | 제목이 `<h2>` | 페이지에서 **가장 중요한 제목(`<h1>`)이 하나도 없음**. 검색엔진과 스크린리더가 페이지 주제를 파악하기 어려움 | Hero 인사말을 `<h1>`으로. 나머지 섹션 제목은 `<h2>` |
| 4 | `<p>`가 4개 나열됨 | Hero는 **3초 안에 "누구인지"** 알려 주는 곳. 글이 많으면 오히려 아무것도 안 읽힘 | 핵심 1~2줄만 남기고, 나머지("호기심", "원리 파악")는 **About 섹션**으로 옮기기 |

## 1. 추천 구성 (Hero에 들어갈 4가지)

Hero는 "명함"이라고 생각하면 쉽습니다. 아래 4개면 충분합니다.

```
┌──────────────────────────────────────────────┐
│  ① 작은 인사 (eyebrow)   "안녕하세요 👋"          │
│  ② 이름 (h1)             "저는 김호재입니다"      │
│  ③ 한 줄 소개 (p)        "'왜?'를 끝까지 파고드는   │
│                          코디세이 올인원 2기"     │
│  ④ CTA 버튼 2개          [프로젝트 보기] [연락하기] │
└──────────────────────────────────────────────┘
```

- **①**은 빼도 됨. 있으면 시선이 위에서 아래로 자연스럽게 흐름
- **②**는 가장 크게. 이름 부분만 강조 색을 주면 포인트가 됨
- **③**은 "나는 어떤 사람인가"를 **한 문장**으로. 지금 쓰신 "호기심이 많고 원리 파악을 좋아한다"를 줄이면 좋음
  - 예: `호기심을 원리로 바꾸는 예비 개발자`
  - 예: `"왜?"를 끝까지 파고드는 코디세이 올인원 2기`
- **④**는 **주 버튼(배경 채움) 1개 + 보조 버튼(테두리만) 1개**로 만들어서 어떤 버튼이 더 중요한지 보이게 하기

## 2. HTML 작성 방법 (직접 써 보세요)

뼈대는 이렇게 잡으면 됩니다. 문구는 본인 스타일로 바꾸세요.

```html
<section id="hero" class="hero">
    <div class="hero-inner">
        <p class="hero-eyebrow">안녕하세요 👋</p>
        <h1 class="hero-title">
            저는 <span class="highlight">김호재</span>입니다
        </h1>
        <p class="hero-desc">
            "왜?"를 끝까지 파고드는 코디세이 올인원 2기
        </p>

        <div class="hero-cta">
            <a href="#projects" class="btn btn-primary">프로젝트 보기</a>
            <a href="#contact" class="btn btn-outline">연락하기</a>
        </div>
    </div>
</section>
```

**포인트**
- `<span class="highlight">`: 이름만 색을 다르게 주기 위한 "손잡이". `<span>`은 의미가 없는 인라인 태그라서 스타일 입히는 용도로 쓰기 좋음
- `.hero-inner`: 내용 폭을 제한하고 가운데로 모으기 위한 감싸는 요소(래퍼)
- `.hero-cta`: 버튼 2개를 Flexbox로 나란히 놓기 위한 래퍼
- class 이름 앞에 `hero-`를 통일해서 붙이면 CSS에서 찾기 쉬움

## 3. CSS 작성 방법

### 3-1. 먼저 `:root`에 변수 정의 (todolist 62~63행)

Hero뿐 아니라 페이지 전체에서 쓸 색이니 `style.css` **맨 위**에 둡니다.

```css
:root {
    --color-bg: #ffffff;
    --color-text: #222222;
    --color-sub: #666666;
    --color-primary: #4f46e5;   /* 포인트 색: 마음에 드는 색으로 */
    --header-height: 64px;
}

[data-theme="dark"] {
    --color-bg: #121212;
    --color-text: #f1f1f1;
    --color-sub: #aaaaaa;
    --color-primary: #818cf8;
}
```

> 색을 변수로 써 두면, **다크 모드(5-e)를 만들 때 Hero CSS는 하나도 안 고쳐도** 색이 저절로 바뀝니다.

### 3-2. Hero 레이아웃: "화면을 꽉 채우고 가운데 정렬"

```css
.hero {
    min-height: 100vh;                 /* 화면 높이만큼 */
    display: flex;
    align-items: center;               /* 세로 가운데 */
    justify-content: center;           /* 가로 가운데 */
    padding: var(--header-height) 1.5rem 0;  /* 고정 헤더에 가려지지 않게 */
    text-align: center;
    background-color: var(--color-bg);
    color: var(--color-text);
}

.hero-inner {
    max-width: 720px;                  /* 한 줄이 너무 길어지지 않게 */
}
```

| 속성 | 의미 |
|---|---|
| `min-height: 100vh` | `vh` = 화면 높이의 1%. 100vh면 첫 화면을 Hero가 꽉 채움 |
| `display: flex` + `align-items` + `justify-content` | 내용을 화면 정중앙에 두는 가장 흔한 방법 |
| `max-width` | 넓은 모니터에서 글이 옆으로 길게 퍼지는 것 막기 |

### 3-3. 글자 크기: 모바일 퍼스트 (todolist 68~69행)

**작은 화면 기준으로 먼저 쓰고**, 큰 화면에서만 키웁니다.

```css
.hero-eyebrow { font-size: 1rem;    color: var(--color-sub); }
.hero-title   { font-size: 2rem;    margin: 0.5rem 0 1rem; }
.hero-desc    { font-size: 1.05rem; color: var(--color-sub); }
.highlight    { color: var(--color-primary); }

@media (min-width: 768px) {
    .hero-title { font-size: 3rem; }
    .hero-desc  { font-size: 1.25rem; }
}

@media (min-width: 1024px) {
    .hero-title { font-size: 3.75rem; }
}
```

> 💡 `clamp()`를 쓰면 미디어 쿼리 없이도 됩니다: `font-size: clamp(2rem, 6vw, 3.75rem);` (괄호 안 순서: 최소, 화면 비율, 최대)

### 3-4. CTA 버튼 (todolist 72행: hover + transition)

```css
.hero-cta {
    display: flex;
    gap: 1rem;
    justify-content: center;
    flex-wrap: wrap;           /* 좁은 화면에서는 줄바꿈 */
    margin-top: 2rem;
}

.btn {
    display: inline-block;
    padding: 0.8rem 1.6rem;
    border-radius: 999px;      /* 알약 모양. 각지게 하려면 8px */
    text-decoration: none;     /* 링크 밑줄 없애기 */
    font-weight: 600;
    border: 2px solid var(--color-primary);
    transition: transform 0.2s, background-color 0.2s, color 0.2s;
}

.btn-primary { background-color: var(--color-primary); color: #fff; }
.btn-outline { background-color: transparent; color: var(--color-primary); }

.btn:hover { transform: translateY(-3px); }
.btn-outline:hover { background-color: var(--color-primary); color: #fff; }
```

### 3-5. (선택) 배경으로 분위기 내기

단색이 심심하면 **그라데이션 한 줄**만 넣어도 느낌이 확 달라집니다. 외부 라이브러리도 필요 없습니다.

```css
.hero {
    background: linear-gradient(135deg, var(--color-bg) 0%, #eef2ff 100%);
}
[data-theme="dark"] .hero {
    background: linear-gradient(135deg, #121212 0%, #1e1b4b 100%);
}
```

> ⚠️ 배경 이미지를 넣을 때는 CSS 파일 위치가 기준이라 `url("../images/파일명")`처럼 앞에 `../`를 붙여야 합니다.

## 4. 레이아웃 스타일 고르기

취향대로 고르세요. **처음이라면 A 추천** (가장 단순하고 반응형 처리도 쉬움).

| 스타일 | 모양 | 장점 | 난이도 |
|---|---|---|---|
| **A. 가운데 정렬** | 글과 버튼이 모두 화면 가운데 | 만들기 쉽고 모바일에서도 그대로 보임 | ⭐ |
| **B. 좌우 분할** | 왼쪽에 글, 오른쪽에 프로필 사진 | 사진이 있으면 개성이 살아남 | ⭐⭐ |
| **C. 전체 화면 배경** | 배경 이미지 + 어두운 반투명 막 위에 흰 글씨 | 첫인상이 강함 | ⭐⭐ |

**B를 고른다면**: 모바일에서는 세로로 쌓고, 태블릿부터 가로로 놓기.

```css
.hero-inner { display: flex; flex-direction: column; gap: 2rem; align-items: center; }

@media (min-width: 768px) {
    .hero-inner { flex-direction: row; text-align: left; max-width: 1000px; }
}
```

> B로 하면 프로필 사진이 Hero와 About에 똑같이 두 번 나올 수 있습니다. 그럴 땐 About에 다른 사진이나 아이콘을 쓰는 걸 생각해 보세요.

## 5. 나중에 연결될 todolist 항목

Hero를 만들 때 미리 생각해 두면 뒤에서 편해집니다.

| todolist | Hero와의 연결 |
|---|---|
| 5-f 스크롤 애니메이션 | Hero 요소에 `class="fade-in"`을 붙여 두면 페이지가 열릴 때 서서히 나타나게 만들 수 있음 |
| 5-d 네비 스타일 변경 | Hero 높이(100vh)를 지나면 헤더 배경이 바뀌는 흐름이 자연스러움 |
| 5-e 다크 모드 | 3-1처럼 색을 변수로 써 두면 Hero는 저절로 바뀜 |
| 12 보너스: 타이핑 효과 | `.hero-desc`나 `.highlight`에 `id`를 붙여 두면, JS로 `textContent`를 한 글자씩 늘려서 만들 수 있음 |

**타이핑 효과 힌트 (보너스, 직접 만들어 보세요)**
1. 보여 줄 문장을 `const text = "..."`로 저장
2. `let index = 0` 상태 변수 준비
3. `setInterval`(또는 `setTimeout`을 반복 호출)로 일정 시간마다 `element.textContent = text.slice(0, index)` 실행 후 `index++`
4. `index`가 `text.length`보다 커지면 `clearInterval`로 멈추기
5. "시간 이벤트 → 상태(index) 변경 → 화면 갱신(textContent)" 흐름을 연습할 수 있음 (todolist 9단계와 같은 원리)

## 6. 작업 순서 체크리스트

- [ ] `<button><a></a></button>`을 `<a class="btn">`로 정리
- [ ] "연락하기" 링크를 `#contact`로 수정
- [ ] 인사말을 `<h1>`로 바꾸고, 이름에 `<span class="highlight">` 넣기
- [ ] 소개 문장을 1~2줄로 줄이고, 나머지는 About으로 옮기기
- [ ] `:root`에 색상 변수 정의
- [ ] `.hero` 레이아웃 (100vh + flex 가운데 정렬)
- [ ] 글자 크기: 모바일 퍼스트 + 미디어 쿼리
- [ ] 버튼 스타일 + hover/transition
- [ ] Chrome 개발자 도구(F12)에서 기기 툴바(Cmd+Shift+M)를 켜고 모바일·태블릿·데스크톱 화면 확인

> ⚠️ 참고: 지금 `style.css`의 `img { max-width: 20%; }`는 **페이지의 모든 이미지**에 적용됩니다. Hero에 사진을 넣으면(B 스타일) 너무 작아질 수 있으니, `img` 전체 대신 `.profile-img`처럼 class로 크기를 정하는 걸 추천합니다.
