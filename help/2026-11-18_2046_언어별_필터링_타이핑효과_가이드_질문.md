## 1. Hero 섹션 타이핑 효과

`<h1>` 안에 `<span class="highlight">김호재</span>` 태그가 들어 있으므로, 단순히 `innerHTML`을 한 글자씩 자르면 `<sp...` 같은 HTML 태그가 화면에 그대로 보입니다.
따라서 **일반 글자 구간**과 **`<span class="highlight">` 구간**을 나누어 글자를 채우는 방식으로 구현하면 안전합니다.

### ① HTML 수정 (`index.html`)
`<h1>`에 JS가 찾을 수 있도록 `id="hero-title"`을 추가합니다. (기존 글자는 JS가 실행되기 전에 잠깐 보일 수 있으니 비워두거나, JS가 시작하자마자 지우고 다시 쓰게 합니다.)

```html
<!-- id="hero-title" 추가 -->
<h1 id="hero-title">안녕하세요 <span class="highlight">김호재</span>입니다.</h1>
```

### ② CSS 추가 (`css/style.css`) — 깜빡이는 커서 & 하이라이트 색상
타이핑되는 느낌을 살리기 위해 글자 끝에 깜빡이는 커서(`|`)를 CSS로 추가합니다.

```css
.highlight {
    color: var(--color-primary); /* 강조할 이름("김호재")을 메인 포인트 색으로 변경 */
}

/* 타이핑 커서 효과를 위한 가상 요소 */
#hero-title.typing::after {
    content: '|'; /* 제목 맨 뒤에 세로 막대(|) 커서 표시 */
    margin-left: 4px; /* 글자와 커서 사이 간격 */
    animation: blink 0.7s infinite; /* 0.7초마다 blink 애니메이션 무한 반복 */
}

@keyframes blink {
    0%, 50% { opacity: 1; } /* 절반 시간 동안은 커서가 보임 */
    51%, 100% { opacity: 0; } /* 나머지 절반 시간 동안은 커서가 사라짐 */
}
```

### ③ JavaScript 추가 (`js/script.js`)
한 글자씩 일정 시간(`100ms`) 간격으로 화면에 추가하는 코드입니다.

```javascript
const heroTitle = document.querySelector('#hero-title'); // 타이핑 효과를 넣을 <h1> 요소 선택

const runTypingEffect = () => {
    // 타이핑할 문장을 조각(일반 글자 / highlight 글자)으로 나누어 배열에 저장
    const parts = [
        { text: '안녕하세요 ', isHighlight: false }, // 1단계: 일반 글자
        { text: '김호재', isHighlight: true },       // 2단계: span.highlight 안에 넣을 글자
        { text: '입니다.', isHighlight: false },     // 3단계: 일반 글자
    ];

    heroTitle.textContent = ''; // 기존에 적혀 있던 글자를 먼저 모두 비움
    heroTitle.classList.add('typing'); // 깜빡이는 커서(|) CSS 클래스 추가

    let partIndex = 0; // 현재 몇 번째 조각(parts[0], parts[1]...)을 치고 있는지 추적
    let charIndex = 0; // 현재 조각에서 몇 번째 글자를 치고 있는지 추적
    let highlightSpan = null; // highlight 구간일 때 사용할 <span> 태그를 담을 변수

    const typeNextChar = () => {
        if (partIndex >= parts.length) { // 모든 조각을 다 쳤으면 종료
            heroTitle.classList.remove('typing'); // 다 쳤으면 커서 제거 (계속 깜빡이게 두려면 이 줄 삭제)
            return; // 함수 종료
        }

        const currentPart = parts[partIndex]; // 현재 타이핑할 조각 객체 가져오기

        if (currentPart.isHighlight) { // 현재 조각이 하이라이트 구간("김호재")이라면
            if (!highlightSpan) { // 아직 <span> 태그를 안 만들었으면
                highlightSpan = document.createElement('span'); // 새 <span> 요소 생성
                highlightSpan.classList.add('highlight'); // class="highlight" 붙이기
                heroTitle.appendChild(highlightSpan); // <h1> 안에 <span> 넣기
            }
            highlightSpan.textContent += currentPart.text[charIndex]; // <span> 안에 한 글자 추가
        } else { // 일반 글자 구간이라면
            heroTitle.append(currentPart.text[charIndex]); // <h1>에 직접 한 글자 추가
        }

        charIndex++; // 다음 글자 인덱스로 이동

        if (charIndex >= currentPart.text.length) { // 현재 조각의 글자를 다 쳤다면
            partIndex++; // 다음 조각으로 넘어감
            charIndex = 0; // 글자 위치는 다시 0으로 초기화
        }

        setTimeout(typeNextChar, 100); // 100ms(0.1초) 뒤에 다음 글자 실행
    };

    typeNextChar(); // 첫 글자 타이핑 시작
};

runTypingEffect(); // 페이지 로드 시 타이핑 효과 실행
```

## 2. 프로젝트 언어별 필터링 (`array.filter()` 활용)

기존 `projectState`에 **현재 선택된 언어(`selectedLanguage`)** 상태를 추가하고, 버튼 클릭 시 상태 변경 → `renderProjects()` 재실행 흐름으로 구현합니다.

### ① HTML 수정 (`index.html`)
`#projects` 섹션 안에서 `#projects-status` 아래, `#projects-grid` 위에 필터 버튼들이 들어갈 공간을 추가합니다.

```html
<section id="projects">
    <h3>프로젝트</h3>
    <div class="status" id="projects-status"></div>
    <div class="project-filters" id="project-filters"></div> <!-- 언어 필터 버튼이 들어갈 자리 -->
    <div class="projects-grid" id="projects-grid"></div>
</section>
```

### ② CSS 추가 (`css/style.css`)
필터 버튼들을 가로로 예쁘게 나열하고, 현재 선택된 버튼(`.active`)을 구분할 수 있게 스타일을 줍니다.

```css
.project-filters {
    display: flex; /* 버튼들을 가로로 나열 */
    justify-content: center; /* 가운데 정렬 */
    flex-wrap: wrap; /* 화면이 좁으면 다음 줄로 자동 줄바꿈 */
    gap: 0.5rem; /* 버튼 사이 간격 */
    margin-top: 1.5rem; /* 위쪽 여백 */
}

.filter-btn {
    padding: 0.4rem 1rem; /* 버튼 안쪽 여백 (위아래 0.4rem, 좌우 1rem) */
    border-radius: 999px; /* 알약 모양으로 둥글게 만듦 */
    border: 1px solid rgba(128, 128, 128, 0.3); /* 연한 테두리 */
    cursor: pointer; /* 마우스를 올리면 손가락 모양 커서 */
    transition: background-color var(--transition), color var(--transition); /* 색상 변경 부드럽게 */
}

.filter-btn.active {
    background-color: var(--color-primary); /* 선택된 버튼은 포인트 배경색 적용 */
    color: #ffffff; /* 선택된 버튼 글자는 흰색으로 변경 */
    border-color: var(--color-primary); /* 테두리도 포인트 색으로 맞춤 */
}
```

### ③ JavaScript 수정 (`js/script.js`)
기존의 `projectState`와 `renderProjects`를 아래와 같이 확장합니다.

```javascript
const projectFilters = document.querySelector('#project-filters'); // 필터 버튼 영역 선택

// 기존 projectState에 selectedLanguage 추가
const projectState = {
    status: 'loading',
    repos: [],
    errorMessage: '',
    selectedLanguage: 'All', // 현재 선택된 언어 상태 (기본값: 'All' = 전체 보기)
};

// 필터 버튼을 화면에 그리는 함수
const renderFilterButtons = () => {
    // 1. 모든 repo의 language를 모으고(map), 중복을 제거(Set)한 뒤 배열로 변환
    // repo.language가 null이면 '기타'로 처리
    const languages = ['All', ...new Set(projectState.repos.map((repo) => repo.language || '기타'))];

    // 2. 언어 목록을 <button> HTML 문자열로 변환
    projectFilters.innerHTML = languages
        .map((lang) => {
            // 현재 선택된 언어와 같으면 'active' 클래스를 붙임
            const activeClass = projectState.selectedLanguage === lang ? 'active' : '';
            return `<button type="button" class="filter-btn ${activeClass}" data-lang="${lang}">${lang}</button>`;
        })
        .join(''); // 배열을 하나의 문자열로 합침

    // 3. 생성된 필터 버튼들에 클릭 이벤트 연결
    const filterBtns = projectFilters.querySelectorAll('.filter-btn'); // 방금 만든 버튼들 모두 선택
    filterBtns.forEach((btn) => {
        btn.addEventListener('click', () => { // 각 버튼 클릭 시
            projectState.selectedLanguage = btn.dataset.lang; // 상태(selectedLanguage)를 클릭한 버튼의 언어로 변경
            renderProjects(); // 바뀐 상태에 맞춰 화면 다시 그리기
        });
    });
};

// 기존 renderProjects 함수 수정
const renderProjects = () => {
    projectsStatus.innerHTML = ''; // 상태 메시지 초기화
    projectFilters.innerHTML = ''; // 필터 버튼 초기화
    projectsGrid.innerHTML = '';   // 카드 그리드 초기화

    if (projectState.status === 'loading') {
        projectsStatus.innerHTML = `
            <div class="spinner"></div>
            <p>프로젝트를 불러오는 중...</p>
        `;
        return;
    }

    if (projectState.status === 'error') {
        projectsStatus.innerHTML = `
            <p>${projectState.errorMessage}</p>
            <button type="button" id="retry-btn">다시 시도</button>
        `;
        const retryBtn = document.querySelector('#retry-btn');
        retryBtn.addEventListener('click', fetchRepos);
        return;
    }

    if (projectState.status === 'empty') {
        projectsStatus.innerHTML = `<p>표시할 프로젝트가 없습니다.</p>`;
        return;
    }

    // 성공 상태일 때: 먼저 필터 버튼 그리기
    renderFilterButtons();

    // array.filter()로 선택된 언어에 맞는 프로젝트만 걸러내기
    const filteredRepos =
        projectState.selectedLanguage === 'All' // 'All'이 선택되어 있으면
            ? projectState.repos // 전체 프로젝트 그대로 사용
            : projectState.repos.filter( // 아니면 조건에 맞는 것만 남김
                  (repo) => (repo.language || '기타') === projectState.selectedLanguage
              );

    // 걸러낸 프로젝트(filteredRepos)만 카드로 변환해서 화면에 출력
    projectsGrid.innerHTML = filteredRepos
        .map((repo) => {
            const { name, description, html_url, stargazers_count, language } = repo;
            return `
            <article class="project-card">
                <h4>${name}</h4>
                <p>${description || '설명이 없습니다.'}</p>
                <div class="project-meta">
                    <span>${language || '기타'}</span>
                    <span>* ${stargazers_count}</span>
                </div>
                <a href="${html_url}" target="_blank" rel="noopener noreferrer">GitHub 보기</a>
            </article>
            `;
        })
        .join('');
};
```
