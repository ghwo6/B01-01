# 가운데 정렬이 안 되는 이유 & 전체 코드 점검

- 일시: 2026-11-14 21:38
- 질문: 내가 실수한 건지 가운데 정렬이 안 돼. 왜야? 파일 하나 만들어서 설명해 주고, 전체적으로 잘못된 거 있나 찾아줘.

---

## 1. 가운데 정렬이 안 되는 이유

현재 `css/style.css` 11~15행:
```css
section {
    max-width: 1000px;
    margin: 0 auto;
    padding: 4rem 1.5rem;
}
```

**`margin: 0 auto;`는 "`<section>` 상자 자체"만 화면 가운데에 놓을 뿐, 그 안의 글자나 버튼까지 가운데 정렬하지는 않기 때문입니다.**

1. 상자 안의 글자(`h1`, `p`, `a`)는 기본값이 **왼쪽 정렬(`text-align: left`)**이라 상자 왼쪽 벽에 붙어 보입니다.
2. 창 너비가 `1000px` 이하이면 상자가 화면을 꽉 채워 `margin: 0 auto;`가 티 나지 않습니다.
3. `<img>`에는 `display: block;`이 걸려 있어, `text-align: center;`만으로는 이미지가 가운데로 오지 않습니다.

### 해결 방법

| 하고 싶은 것 | 추가할 CSS |
|---|---|
| **글자와 `<a>` 버튼 가운데로** | `text-align: center;` (예: `section { text-align: center; }`) |
| **`<img>` 같은 `block` 요소 가운데로** | `.profile-img { margin: 0 auto; }` 또는 부모에 `display: flex; flex-direction: column; align-items: center;` |
| **Hero를 화면 정중앙(세로+가로)에** | `#hero`에 `min-height: calc(100vh - var(--header-height)); display: flex; flex-direction: column; justify-content: center; align-items: center; text-align: center;` |

## 2. 전체 코드 점검 (`index.html`, `css/style.css`, `js/script.js`)

### 🔴 꼭 고쳐야 하는 버그 (동작 안 됨)
1. **`index.html` 18행: `<script>`에 `defer` 누락**
   - 현재 `<script src="js/script.js"></script>` → `<script src="js/script.js" defer></script>`로 수정 필요.
   - `<head>`에 `defer` 없이 넣으면 `<body>`를 읽기 전에 JS가 실행되어 `hamburgerBtn`이 `null`이 되고, **햄버거 클릭과 스크롤 이벤트가 아예 동작하지 않습니다.** (`todolist.md` 35행)
2. **`index.html` 10행: Google Fonts URL 오타**
   - `https://fonts.goolgeapis.com` → `https://fonts.googleapis.com`

### 🟡 HTML 문법 / 구조 (`index.html`)
3. **22행:** `<header class ="header">` → `class`와 `=` 사이 공백 제거 (`class="header"`).
4. **37~41행:** 제목 태그 순서가 `<h2>` → `<h1>` → `<h3>`로 뒤바뀜. 가장 큰 제목인 `<h1>`이 먼저 오고, 인사말·설명은 `<p>`로 쓰는 것이 시맨틱 HTML에 맞습니다.
5. **57~64행:** `<ul>기술 스택</ul>`처럼 `<ul>` 안에 `<li>` 없이 텍스트만 넣으면 문법 오류입니다. 제목은 `<h2>`, 목록은 `<ul><li>파이썬</li></ul>`으로 바꾸세요. 또한 `id="Learing"`은 `Learning` 오타입니다 (`id="learning"` 권장).
6. **70행:** `<button type="button" class="scroll-top">↑</button>`처럼 `type="button"` 추가 권장.
7. **`todolist.md` 참고:** `<meta name="description" content="...">` 미작성(37행), `todolist`상 JS 파일명은 `js/main.js`(현재 `js/script.js`).

### 🟢 CSS (`css/style.css`)
8. **20~21행:** `font-family: var(--font-main);` 두 번 중복 작성됨.
9. **34~38행:** `img { max-width: 20%; }`는 모든 이미지에 적용되어 모바일에서 너무 작아집니다. `.profile-img` 클래스에만 크기를 지정하는 편이 좋습니다.
10. **미정의 클래스:** HTML에 `class="highlight"`, `class="btn"`이 있지만 CSS에 아직 스타일 규칙이 없어 기본 모양으로 보입니다.
