# 간단한 Hero 타이핑 효과 & 언어별 필터링 구현 가이드

- **질문 일시:** 2026-11-18 20:49
- **질문 내용:** `<h1>안녕하세요 김호재입니다.</h1>` 순수 텍스트 버전으로 단순화한 타이핑 효과와 프로젝트 언어별 필터링 가이드 새 문서 작성 요청

## 1. Hero 섹션 타이핑 효과 (초간단 순수 텍스트 버전)

`<h1>` 안에 `<span>`이나 `<b>` 같은 태그를 빼고 **순수 텍스트만** 두면, `textContent`와 `slice()`만으로 아주 짧고 쉽게 구현할 수 있습니다.

### ① HTML 수정 (`index.html`)
`<span>`을 제거하고 `id="hero-title"`만 추가합니다.

```html
<!-- span 태그를 빼고 id="hero-title" 추가 -->
<h1 id="hero-title">안녕하세요 김호재입니다.</h1>
```

### ② CSS 추가 (`css/style.css`) — 깜빡이는 커서
글자 뒤에서 세로 막대(`|`)가 깜빡이는 커서 효과를 만듭니다.

```css
/* 타이핑 중일 때 글자 뒤에 커서(|) 표시 */
#hero-title.typing::after {
    content: '|'; /* 제목 맨 뒤에 세로 막대(|) 문자 추가 */
    margin-left: 4px; /* 마지막 글자와 커서 사이 간격 */
    animation: blink 0.7s infinite; /* 0.7초 간격으로 blink 애니메이션 무한 반복 */
}

@keyframes blink {
    0%, 50% { opacity: 1; } /* 앞의 절반 시간 동안 커서가 보임 */
    51%, 100% { opacity: 0; } /* 뒤의 절반 시간 동안 커서가 안 보임 */
}
```

### ③ JavaScript 추가 (`js/script.js`)

```javascript
const heroTitle = document.querySelector('#hero-title'); // HTML에서 id="hero-title"인 <h1> 요소 선택
const text = '안녕하세요 김호재입니다.'; // 화면에 한 글자씩 타이핑할 전체 문장
let index = 0; // 현재 몇 번째 글자까지 보여줄지 기억하는 변수 (0부터 시작)

heroTitle.textContent = ''; // 페이지가 열리자마자 기존 글자를 비움
heroTitle.classList.add('typing'); // 깜빡이는 커서(|)를 보이게 하기 위해 'typing' 클래스 추가

const typeText = () => {
    heroTitle.textContent = text.slice(0, index + 1); // 문장의 처음(0)부터 (index + 1)번째 글자까지 잘라서 화면에 넣음
    index++; // 다음 글자를 보여주기 위해 index를 1 증가시킴

    if (index < text.length) { // 아직 출력할 글자가 문장 길이보다 작다면 (남은 글자가 있으면)
        setTimeout(typeText, 100); // 100ms(0.1초) 기다렸다가 typeText 함수를 다시 실행
    } else { // 모든 글자를 다 출력했다면
        heroTitle.classList.remove('typing'); // 타이핑이 끝났으니 커서 제거 (계속 깜빡이게 하려면 이 줄 삭제)
    }
};

typeText(); // 타이핑 함수 첫 실행
```

## 2. 프로젝트 언어별 필터링 (`array.filter()` 활용)

기존 `projectState`에 **현재 선택된 언어(`selectedLanguage`)** 상태를 추가하고, 버튼 클릭 시 상태 변경 → `renderProjects()` 재실행 흐름으로 구현합니다.

### ① HTML 수정 (`index.html`)
`#projects` 섹션 안에서 `#projects-status` 아래, `#projects-grid` 위에 필터 버튼 영역을 추가합니다.

```html
<section id="projects">
    <h3>프로젝트</h3>
    <div class="status" id="projects-status"></div>
    <div class="project-filters" id="project-filters"></div> <!-- 언어 필터 버튼들이 들어갈 자리 -->
    <div class="projects-grid" id="projects-grid"></div>
</section>
```

### ② CSS 추가 (`css/style.css`)

```css
.project-filters {
    display: flex; /* 버튼들을 가로 방향으로 나열 */
    justify-content: center; /* 버튼 묶음을 가운데 정렬 */
    flex-wrap: wrap; /* 화면이 좁아서 버튼이 넘치면 자동으로 다음 줄로 내림 */
    gap: 0.5rem; /* 버튼과 버튼 사이 간격 */
    margin-top: 1.5rem; /* 위쪽 제목과의 여백 */
}

.filter-btn {
    padding: 0.4rem 1rem; /* 버튼 안쪽 여백 (위아래 0.4rem, 좌우 1rem) */
    border-radius: 999px; /* 모서리를 크게 둥글게 해서 알약 모양으로 만듦 */
    border: 1px solid rgba(128, 128, 128, 0.3); /* 1px 두께의 연한 회색 테두리 */
    cursor: pointer; /* 마우스를 올리면 손가락 모양 커서로 변경 */
    transition: background-color var(--transition), color var(--transition); /* 색상이 바뀔 때 부드럽게 전환 */
}

.filter-btn.active {
    background-color: var(--color-primary); /* 현재 선택된 버튼은 포인트 배경색 적용 */
    color: #ffffff; /* 선택된 버튼 글자색은 흰색으로 변경 */
    border-color: var(--color-primary); /* 테두리 색도 포인트 색으로 통일 */
}
```

### ③ JavaScript 수정 (`js/script.js`)
기존의 `projectState`와 `renderProjects`를 아래 내용에 맞춰 수정합니다.

```javascript
const projectFilters = document.querySelector('#project-filters'); // 필터 버튼들을 넣을 <div> 선택

// 기존 projectState 객체에 selectedLanguage 속성 추가
const projectState = {
    status: 'loading',
    repos: [],
    errorMessage: '',
    selectedLanguage: 'All', // 현재 선택된 언어 상태 (기본값 'All' = 전체 보기)
};

// 언어 필터 버튼들을 화면에 그려주는 함수
const renderFilterButtons = () => {
    // 1. 모든 저장소(repos)에서 language만 뽑아내고(map), Set으로 중복을 제거한 뒤, 맨 앞에 'All'을 붙여서 배열 생성
    // repo.language가 비어있으면(null) '기타'라는 이름으로 묶음
    const languages = ['All', ...new Set(projectState.repos.map((repo) => repo.language || '기타'))];

    // 2. 언어 배열을 <button> HTML 문자열 목록으로 변환(map)하고 하나로 합침(join)
    projectFilters.innerHTML = languages
        .map((lang) => {
            // 지금 만드는 버튼의 언어(lang)가 현재 선택된 언어와 같으면 'active' 클래스를 붙임
            const activeClass = projectState.selectedLanguage === lang ? 'active' : '';
            // data-lang 속성에 언어 이름을 저장해 두어 클릭 시 어떤 언어인지 알 수 있게 함
            return `<button type="button" class="filter-btn ${activeClass}" data-lang="${lang}">${lang}</button>`;
        })
        .join('');

    // 3. 방금 화면에 만든 필터 버튼들에 클릭 이벤트 연결
    const filterBtns = projectFilters.querySelectorAll('.filter-btn'); // 모든 필터 버튼 선택
    filterBtns.forEach((btn) => { // 버튼을 하나씩 꺼내서 반복
        btn.addEventListener('click', () => { // 버튼이 클릭되면
            projectState.selectedLanguage = btn.dataset.lang; // 선택된 언어 상태를 클릭한 버튼의 data-lang 값으로 변경
            renderProjects(); // 바뀐 상태에 맞춰 프로젝트 목록과 버튼을 다시 그림
        });
    });
};

// 기존 renderProjects 함수 수정
const renderProjects = () => {
    projectsStatus.innerHTML = ''; // 상태 메시지 영역 비우기
    projectFilters.innerHTML = ''; // 필터 버튼 영역 비우기
    projectsGrid.innerHTML = '';   // 프로젝트 카드 영역 비우기

    if (projectState.status === 'loading') {
        projectsStatus.innerHTML = `
            <div class="spinner"></div>
            <p>프로젝트를 불러오는 중...</p>
        `;
        return;
    }

    if (projectState.status === 'error') {
        projectsStatus.innerHTML = `
            <p>${projectState.errorMessage}</p>
            <button type="button" id="retry-btn">다시 시도</button>
        `;
        const retryBtn = document.querySelector('#retry-btn');
        retryBtn.addEventListener('click', fetchRepos);
        return;
    }

    if (projectState.status === 'empty') {
        projectsStatus.innerHTML = `<p>표시할 프로젝트가 없습니다.</p>`;
        return;
    }

    // 성공 상태일 때: 먼저 필터 버튼들을 그림
    renderFilterButtons();

    // array.filter()를 사용해 현재 선택된 언어에 해당하는 프로젝트만 골라냄
    const filteredRepos =
        projectState.selectedLanguage === 'All' // 선택된 언어가 'All'이면
            ? projectState.repos // 전체 저장소를 그대로 사용
            : projectState.repos.filter( // 'All'이 아니면 조건에 맞는 저장소만 남김
                  (repo) => (repo.language || '기타') === projectState.selectedLanguage
              );

    // 걸러낸 목록(filteredRepos)을 map()으로 카드 HTML로 변환해서 화면에 출력
    projectsGrid.innerHTML = filteredRepos
        .map((repo) => {
            const { name, description, html_url, stargazers_count, language } = repo;
            return `
            <article class="project-card">
                <h4>${name}</h4>
                <p>${description || '설명이 없습니다.'}</p>
                <div class="project-meta">
                    <span>${language || '기타'}</span>
                    <span>* ${stargazers_count}</span>
                </div>
                <a href="${html_url}" target="_blank" rel="noopener noreferrer">GitHub 보기</a>
            </article>
            `;
        })
        .join('');
};
```
