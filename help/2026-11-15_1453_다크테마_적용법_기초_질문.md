## 1. 기초 지식: 다크 모드는 어떻게 동작할까?

다크 모드는 크게 **3가지 조각**이 맞물려 돌아갑니다.

| 담당 | 하는 일 | `todolist.md` 항목 |
|---|---|---|
| **CSS** | 변수(`:root`)와 다크 모드 변수(`[data-theme="dark"]`) 정의 | 3단계 (62~63행) |
| **JS (DOM)** | `<html>` 태그에 `data-theme="dark"` 속성을 붙였다 떼기 | 5-e (97행) |
| **JS (저장소)** | 선택한 테마를 브라우저 `localStorage`에 저장·불러오기 | 5-e (98행) |

### ① `document.documentElement.dataset.theme`란?
- `document.documentElement`는 HTML 문서의 가장 바깥 태그인 **`<html>`**을 가리킵니다.
- `.dataset.theme = 'dark'`를 실행하면 HTML이 아래처럼 바뀝니다.
  ```html
  <html lang="ko" data-theme="dark">
  ```
- 그러면 CSS에 적어 둔 `[data-theme="dark"] { ... }`가 즉시 켜지면서 `--color-bg`, `--color-text` 등의 변수 값이 어두운 색으로 바뀝니다.
- 라이트 모드로 돌아갈 때는 `.dataset.theme = 'light'`로 바꾸거나 `delete document.documentElement.dataset.theme`로 속성을 지웁니다.

### ② `localStorage`란?
- 브라우저 안에 작은 데이터를 **새로고침하거나 창을 닫았다 열어도 사라지지 않게 저장**하는 공간입니다. (문자열만 저장 가능)
- 자주 쓰는 메서드 2개:
  - 저장하기: `localStorage.setItem('theme', 'dark')`
  - 꺼내오기: `localStorage.getItem('theme')` → 저장된 게 없으면 `null` 반환

## 2. 현재 내 프로젝트 상태 확인 (`css/style.css` & `index.html`)

이미 잘 준비되어 있는 부분이 많습니다!
- `index.html`: `<button type="button" class="theme-toggle">다크 모드</button>` 있음
- `css/style.css`: `:root`와 `[data-theme="dark"]` 이미 작성되어 있음!

### CSS에서 추가로 챙길 점
1. **직접 색(`#333`, `black` 등)을 쓰지 말고 항상 `var(--...)` 사용하기**
   - `a` 태그(링크)는 브라우저 기본 색(파란색/보라색)이 있어서 다크 배경에서 어둡게 보일 수 있습니다.
   - 아래처럼 `a { color: inherit; }` 또는 `color: var(--color-text);`를 주면 다크 모드에서도 글자가 잘 보입니다.
2. **부드러운 색 전환 효과 (`transition`)**
   - `body`, `.header`, `button` 등에 `transition: background-color var(--transition), color var(--transition);`을 넣으면 테마가 바뀔 때 화면이 부드럽게 전환됩니다.

## 3. 예제 코드 (`todolist` 9단계 "상태 관리 패턴" 반영)

`todolist.md` 9단계의 핵심은 **"사용자 이벤트 → 상태 변경 → 화면 업데이트(렌더링)"** 흐름이 코드에서 명확히 보이게 만드는 것입니다.

```javascript
// 1. DOM 요소 선택
const themeToggleBtn = document.querySelector('.theme-toggle');

// 2. 상태(State): 현재 테마를 저장 (페이지 열 때 localStorage에서 먼저 읽어옴)
let currentTheme = localStorage.getItem('theme') || 'light';

// 3. 렌더링 함수(Render): 현재 상태에 맞게 화면(HTML 속성 + 버튼 글자)을 그림
const applyTheme = (theme) => {
    document.documentElement.dataset.theme = theme;
    themeToggleBtn.textContent = theme === 'dark' ? '라이트 모드' : '다크 모드';
};

// 4. 페이지 처음 로드될 때 저장된 테마 적용
applyTheme(currentTheme);

// 5. 사용자 이벤트: 버튼 클릭 → 상태 변경 → 저장 → 화면 업데이트
themeToggleBtn.addEventListener('click', () => {
    currentTheme = currentTheme === 'dark' ? 'light' : 'dark';
    localStorage.setItem('theme', currentTheme);
    applyTheme(currentTheme);
});
```

### 한 줄씩 이해하기
1. `localStorage.getItem('theme') || 'light'`
   - 처음 방문해서 저장된 값이 `null`이면 기본값 `'light'`를 씁니다.
2. `applyTheme(currentTheme)`
   - 페이지가 열리자마자 실행해서, 이전에 다크 모드를 켜 뒀다면 **새로고침해도 다크 모드가 유지**되게 합니다.
3. `theme === 'dark' ? '라이트 모드' : '다크 모드'` (삼항 연산자)
   - 현재 다크 모드면 버튼 글자를 `"라이트 모드"`로 바꿔서 다음에 누르면 무엇이 될지 알려 줍니다.
4. **`todolist.md` 0단계 제약 사항 체크:**
   - `var` 대신 `const`, `let`만 사용 ✅
   - `onclick` 대신 `addEventListener` 사용 ✅
   - 인라인 스타일(`style="..."`) 사용 안 함 ✅

### 문법 짚고 가기: `const applyTheme = (theme) => { ... };`

이 문법은 **화살표 함수(Arrow Function)**라고 부르며, 함수를 만들어 `applyTheme`이라는 이름(변수)에 저장하는 코드입니다.

#### ① `function` 방식과 비교하면?
아래 두 코드는 사실상 똑같은 일을 합니다.
```javascript
// 1) 기존 방식 (function 키워드 사용)
function applyTheme(theme) {
    document.documentElement.dataset.theme = theme;
}

// 2) 화살표 함수 방식 (ES6+ 최신 문법, todolist 7단계)
const applyTheme = (theme) => {
    document.documentElement.dataset.theme = theme;
};
```
- `const` 변수에 함수를 담아 두므로 나중에 실수로 같은 이름으로 덮어쓰는 것을 막아 줍니다.

#### ② 화살표(`=>`)는 왜 붙이나요?
- `function`이라는 긴 단어 대신 **"왼쪽 값(`theme`)을 받아서 →(`=>`) 오른쪽 `{ ... }` 코드를 실행한다"**는 뜻을 간결하게 나타내기 위해 씁니다.
- `todolist.md` 7단계("ES6+ 문법")에서도 권장하는 현대 자바스크립트 표준 문법입니다.

#### ③ `theme`에 `()` 괄호를 치는 이유는?
- `(theme)`는 함수 밖에서 값을 넘겨받는 **입력창(매개변수, Parameter)**입니다.
  - `applyTheme('dark')`로 실행하면 `theme` 자리에 `'dark'`가 들어갑니다.
  - `applyTheme('light')`로 실행하면 `theme` 자리에 `'light'`가 들어갑니다.
- **괄호 생략 규칙:**
  | 매개변수 개수 | 문법 | 괄호 생략 가능? |
  |---|---|---|
  | **0개** (예: 클릭 이벤트 콜백) | `() => { ... }` | ❌ 괄호 필수 |
  | **1개** (예: `theme`) | `(theme) => { ... }` 또는 `theme => { ... }` | ⭕ 생략 가능 |
  | **2개 이상** | `(a, b) => { ... }` | ❌ 괄호 필수 |
  - 1개일 때는 `theme =>`처럼 괄호를 빼도 똑같이 동작하지만, 0개·2개일 때와 모양을 통일해서 한눈에 "함수 입력값"임을 알아보기 쉽게 `(theme)`로 쓰는 경우가 많습니다.

## 4. 보너스 (선택): 시스템 다크 모드 감지 (`todolist` 12단계)

사용자가 `localStorage`에 따로 저장한 기록이 없을 때, OS(맥/윈도우)의 다크 모드 설정을 자동으로 따라가게 하려면 2번 줄을 이렇게 바꿀 수 있습니다.

```javascript
const prefersDark = window.matchMedia('(prefers-color-scheme: dark)').matches;
let currentTheme = localStorage.getItem('theme') || (prefersDark ? 'dark' : 'light');
```
