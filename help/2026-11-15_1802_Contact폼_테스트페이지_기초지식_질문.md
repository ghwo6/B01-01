# Contact 폼 기초 지식 & 테스트 페이지 구성 방법 (`/example/04_contact_form`)

- 일시: 2026-11-15 18:02
- 질문: Contact 폼도 `/example/04_contact_form`에 만들어서 테스트해 보려고 하는데, 필요한 기초 지식과 작성 방법을 알려줘.

---

## 1. 꼭 알아야 할 기초 지식 5가지 (`todolist.md` 2, 4, 6, 9단계)

1. **`<label for="...">` ↔ `<input id="...">` 연결**
   - `for` 값과 `id` 값을 똑같이 맞추면, 라벨 글자("이메일")를 클릭해도 입력창에 커서가 들어가고 스크린리더 접근성도 좋아집니다.
2. **`<form novalidate>`**
   - `<input type="email">`이나 `required`를 쓰면 브라우저 기본 말풍선 경고가 먼저 떠서, 우리가 JS로 만든 에러 메시지가 가려질 수 있습니다.
   - `<form id="contact-form" novalidate>`처럼 `novalidate`를 붙이면 브라우저 기본 경고를 끄고 **JS로 직접 만든 에러 메시지**를 깔끔하게 보여줄 수 있습니다.
3. **`submit` 이벤트와 `event.preventDefault()`**
   - `<form>`은 전송 버튼을 누르면 기본적으로 **페이지를 새로고침**합니다.
   - `form.addEventListener('submit', (event) => { event.preventDefault(); ... })`로 기본 새로고침을 막아야 JS 검증이 동작합니다.
4. **이메일 형식 검증 (정규식)**
   - `/^[^\s@]+@[^\s@]+\.[^\s@]+$/` 정규식에 `.test(값)`을 쓰면 `@`와 `.`이 올바르게 들어갔는지 `true` / `false`로 확인할 수 있습니다.
5. **실시간 에러 숨김 (`input` 이벤트)**
   - 제출 시 에러가 떴더라도, 사용자가 입력창에 다시 글자를 입력하는 순간(`input` 이벤트) 즉시 검증해서 에러 메시지를 지워주면 사용자 경험(UX)이 좋아집니다.

## 3. 테스트용 뼈대 코드

### ① `index.html`
```html
<!DOCTYPE html>
<html lang="ko">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Contact 폼 테스트</title>
    <link rel="stylesheet" href="style.css">
    <script src="script.js" defer></script>
</head>
<body>
    <main>
        <h1>문의하기</h1>

        <form id="contact-form" novalidate>
            <div class="form-group">
                <label for="name">이름</label>
                <input type="text" id="name" placeholder="이름을 입력하세요">
                <p class="error-msg" id="name-error"></p>
            </div>

            <div class="form-group">
                <label for="email">이메일</label>
                <input type="email" id="email" placeholder="example@email.com">
                <p class="error-msg" id="email-error"></p>
            </div>

            <div class="form-group">
                <label for="message">메시지</label>
                <textarea id="message" rows="4" placeholder="문의 내용을 입력하세요"></textarea>
                <p class="error-msg" id="message-error"></p>
            </div>

            <button type="submit">보내기</button>
            <p class="success-msg" id="success-msg"></p>
        </form>
    </main>
</body>
</html>
```

### ③ `script.js` (`상태 → 렌더링` 패턴)
```javascript
const form = document.querySelector('#contact-form');
const nameInput = document.querySelector('#name');
const emailInput = document.querySelector('#email');
const messageInput = document.querySelector('#message');

const nameError = document.querySelector('#name-error');
const emailError = document.querySelector('#email-error');
const messageError = document.querySelector('#message-error');
const successMsg = document.querySelector('#success-msg');

const emailRegex = /^[^\s@]+@[^\s@]+\.[^\s@]+$/;

// 개별 필드 검증 후 에러 메시지 반환 (통과면 빈 문자열 '')
const getNameError = (val) => (val.trim() === '' ? '이름을 입력해 주세요.' : '');
const getEmailError = (val) => {
    if (val.trim() === '') return '이메일을 입력해 주세요.';
    if (!emailRegex.test(val.trim())) return '올바른 이메일 형식이 아닙니다.';
    return '';
};
const getMessageError = (val) => (val.trim() === '' ? '메시지를 입력해 주세요.' : '');

// 렌더링 헬퍼: 입력창 테두리 + 에러 문구 업데이트
const showFieldError = (inputEl, errorEl, msg) => {
    errorEl.textContent = msg;
    inputEl.classList.toggle('invalid', msg !== '');
};

// 실시간 검증 (input 이벤트)
nameInput.addEventListener('input', () => showFieldError(nameInput, nameError, getNameError(nameInput.value)));
emailInput.addEventListener('input', () => showFieldError(emailInput, emailError, getEmailError(emailInput.value)));
messageInput.addEventListener('input', () => showFieldError(messageInput, messageError, getMessageError(messageInput.value)));

// 제출 검증 (submit 이벤트)
form.addEventListener('submit', (event) => {
    event.preventDefault(); // 새로고침 방지
    successMsg.textContent = '';

    const nErr = getNameError(nameInput.value);
    const eErr = getEmailError(emailInput.value);
    const mErr = getMessageError(messageInput.value);

    showFieldError(nameInput, nameError, nErr);
    showFieldError(emailInput, emailError, eErr);
    showFieldError(messageInput, messageError, mErr);

    if (!nErr && !eErr && !mErr) {
        successMsg.textContent = '문의가 성공적으로 접수되었습니다!';
        form.reset(); // 입력창 초기화
    }
});
```
